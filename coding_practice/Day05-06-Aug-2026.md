🔹 Ansible Task — Install Nginx on Pathnex Server

- name: Install Nginx on Pathnex server
  hosts: all
  become: yes

  tasks:
    - name: Install nginx
      yum:
        name: nginx
        state: present


🔹 Docker
# Docker Installation & First Container
docker --version
docker run ubuntu echo "Hello Pathnex"


# Docker File
FROM ubuntu:22.04
CMD ["echo", "Hello Pathnex"]

----------------------------------------------------------------
# **Explanation of Code:**
## Part 1: Ansible Playbook
**1. Play Name**
 - name: Install Nginx on Pathnex server

name is a description of the play. It tells anyone reading the playbook what it does.

**2. Hosts :** This tells Ansible which machines to execute the playbook on.
**3. Become :** become: yes
Run commands as the root (administrator) user.
Without it: yum install nginx
may fail with:
With become: yes, Ansible effectively runs: sudo yum install nginx

**4. Tasks :** A playbook contains one or more tasks. Each task performs one action. Example:
Install package
Create user
Copy file
Start service

**5. Task Name :** - name: Install nginx
This is a readable label shown while Ansible runs.

**6. Yum Module:** yum is an Ansible module used on RHEL, CentOS, and Amazon Linux to manage packages.

**7. Package Name:** name: nginx
The package to install.

**8. State :**  state: present
present means: Ensure the package is installed.
If Nginx is already installed, Ansible does nothing.
This is called idempotency.
Other common values: state: latest
Installs or upgrades to the latest version.
state: absent
Removes the package.

**What Happens When This Playbook Runs?**
Connects to all target servers.
Uses sudo (become: yes).
Checks whether Nginx is installed.
If not installed, installs it.
If already installed, reports no changes.

## Part 2: Docker
1. Check Docker Version : docker --version

2. Run Your First Container : docker run ubuntu echo "Hello Pathnex"
ubuntu : The Docker image to use.
If it isn't available locally, Docker automatically downloads it.
echo "Hello Pathnex" : The command to run inside the container.

# Docker File 
A Dockerfile contains instructions for building a custom Docker image.
1. FROM ubuntu:22.04 : This specifies the base image.
2. CMD ["echo", "Hello Pathnex"]
CMD defines the default command that runs when a container starts from the image. When the container starts, it executes: echo "Hello Pathnex"

------------------------------------------------
**Build the Docker Image**
docker build -t myimage .

Explanation:
docker build - Builds an image.
-t myimage - Tags (names) the image as myimage.
. - Uses the current directory, where the Dockerfile is located.

Run the Image : docker run myimage

Output: Hello Pathnex
